# Document Dashboard

A React + TypeScript frontend for the [DocumentManagerApi](https://github.com/ckim53/DocumentManagerApi).

Live Demo: https://doc-manager.up.railway.app/

## Stack

- React + TypeScript (Vite)
- Recharts for tag frequency visualization
- Connects to ASP.NET Core REST API

## Run

Make sure DocumentManagerApi is running on port 5000, then:

```bash
npm install
npm run dev
```

## Features

- Create documents with validation feedback
- Filter documents by tag
- Delete documents
- Tag frequency bar chart
